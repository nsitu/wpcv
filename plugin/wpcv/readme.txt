A starting point for custom WordPress functionality.

== Description ==

Provides lifecycle hooks and an administrator-only status page under Tools > WPCV.

== Installation ==

1. Upload wpcv.zip through Plugins > Add New Plugin > Upload Plugin, or deploy with the repository's GitHub Actions workflow.
2. Activate WPCV.
3. Visit Tools > WPCV to confirm the installed version.
